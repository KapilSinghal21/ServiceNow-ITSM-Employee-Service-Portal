# Notification Catalog

## Incident Assigned
When:
- Incident assignment group/assignee changes

Recipient:
- Assigned user

Subject:
`Incident ${number} assigned to you`

## Approval Requested
When:
- Approval record is requested

Recipient:
- Approver

## Request Approved
When:
- Request approval becomes Approved

Recipient:
- Requested For

## Request Rejected
When:
- Request approval becomes Rejected

Recipient:
- Requested For

## Fulfillment Completed
When:
- Fulfillment task closes

Recipient:
- Requested For

## Incident Resolved
When:
- Incident state becomes Resolved

Recipient:
- Caller
